Mac, the Terminal way

One line after the download. It makes the file runnable, clears the quarantine flag macOS puts on downloads, and starts it. Change arm64 to intel on an Intel Mac.

cd ~/Downloads && chmod +x donutcoin-macos-arm64 && xattr -d com.apple.quarantine donutcoin-macos-arm64; ./donutcoin-macos-arm64

Right-click, Open no longer works for command-line programs on macOS 15 and later; only Open Anyway in Privacy & Security, or the line above, does.

Or, if you have Python

Mac or Linux:

curl -fsSL https://donutcoin.meme/install.sh | bash

Windows, in PowerShell:

irm https://donutcoin.meme/install.ps1 | iex

Or, with Docker

A full node, its explorer and the wallet, in one command. It runs as an unprivileged user, keeps everything in a named volume, and mines nothing unless you ask it to.

git clone https://donutcoin.meme/source donutcoin && cd donutcoin
docker compose up -d        # then http://localhost:8555

Or pull the prebuilt image instead of building. It is multi-arch, so it covers a Raspberry Pi as well as an ordinary PC, and a new one is published with every release: the image and its one-line pull command are here.

docker compose down -v removes it and its data completely. Back up wallet.json from the volume first if you have mined anything: it is your keys, and it is the only file here that cannot be downloaded again.

What you get

The same program either way: donutcoin start mines, donutcoin wallet holds and sends, donutcoin node runs a full node with its own explorer at http://localhost:8555. The source is MIT-licensed and short enough to read in an evening.
